Instalar certificado / Remover aviso de segurança

O navegador avisa porque este servidor usa um certificado autoassinado (desenvolvimento/rede local). O site não consegue instalar a autoridade raiz sozinho — isso seria uma falha de segurança. Você precisa baixar e instalar o certificado neste Windows (uma vez por usuário/máquina).

Baixar certificado (.cer) Baixar instalador (.bat) Baixar script PowerShell (.ps1)

Opção A — instalador (recomendado no Windows)

  1. Clique em Baixar instalador (.bat).
  2. Abra o arquivo baixado (pode aparecer SmartScreen → “Mais informações” → “Executar assim mesmo”).
  3. O script baixa o certificado público via HTTP e importa em Usuário atual → Autoridades de Certificação Raiz Confiáveis. Confirme se o Windows pedir.
  4. Feche e reabra o Chrome/Edge por completo.
  5. Abra de novo o site em HTTPS (ex.: https://127.0.0.1/).

Se o download automático falhar, baixe também o .cer, coloque na mesma pasta do .bat e execute o instalador de novo.

Opção B — instalar o .cer manualmente

  1. Baixe o certificado (sao-geraldo-local.cer).
  2. Clique duas vezes no arquivo → Instalar certificado…
  3. Escolha Usuário atual → Avançar.
  4. Marque Colocar todos os certificados no repositório a seguir.
  5. Repositório: Autoridades de Certificação Raiz Confiáveis → OK → Avançar → Concluir.
  6. Aceite o aviso de segurança do Windows (é o cert local deste app).
  7. Reinicie o navegador e reabra o HTTPS.

O que você ainda precisa fazer manualmente

  • Baixar o .cer e/ou o instalador
  • Executar o instalador (ou o assistente do .cer) e confirmar no Windows
  • Reiniciar o navegador
  • Reabrir a URL HTTPS

Vale só para este usuário nesta máquina. Em produção use domínio real + CA pública (Let’s Encrypt, etc.). A chave privada (certs/key.pem) nunca é oferecida para download.
